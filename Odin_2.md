#### Odin 2 v1.0.0.387 (2025-09-10)
<details>
<summary>View changes</summary>

- Fixed screen freezes and line artifacts introduced after the previous OTA.
- Fixed system time synchronization issues.
- Fixed an issue where selecting Korean language displayed Chinese text.
- Added 1080p (portrait) option in Odin Settings → Video Output Mode.
- Added back key mapping feature in Odin Settings.

</details>

#### Odin 2 v1.0.0.380 (2025-08-15)
<details>
<summary>View changes</summary>

- Reverted fan speed control behavior to the previous version.
- Further optimized touch ghosting issues.

</details>

#### Odin 2 v1.0.0.340 (2025-05-22)
<details>
<summary>View changes</summary>

- Improved brightness adjustment behavior for smoother changes at low levels.
- Fixed Drastic emulator display issues when using full-screen or aspect ratio modes on external displays.
- Fixed external monitors displaying in portrait mode when Force Desktop Mode was enabled.
- Fixed system reboots during extended gameplay with vibration-enabled Bluetooth controllers when built-in controllers were disabled.
- Fixed microphone audio not working during TikTok livestreams.
- Updated controller behavior so Xbox mode applies consistently across standby unlock, button mapping, and virtual mouse.
- Improved file transfer stability during large transfers.
- Added customizable LED settings with color and advanced configuration options.

</details>

</details>

### 2024
<details>
<summary>View 2024 updates</summary>

#### Odin 2 v1.0.0.318 (2024-07-25)
<details>
<summary>View changes</summary>

- Fixed frame drops during PS5 streaming.
- Fixed inability to connect to iPhone Wi-Fi hotspots.
- Fixed frame drops when joystick was rotated to 90 degrees.
- Fixed lag when rapidly switching controller styles and trigger input modes.
- Fixed Google Quick Share not functioning.
- Fixed incomplete display issues in the Vita3K emulator.
- Updated Korean translation in Odin Launcher.
- Fixed notifications not fully displaying at 600dp.
- Fixed built-in controller issues in Winlator when using joystick, buttons, and L2/R2 simultaneously.
- Fixed screen dimming when moving joystick in certain games (requires adding affected games to whitelist).

</details>

#### Odin 2 v1.0.0.296 (2024-05-17)
<details>
<summary>View changes</summary>

- Improved volume linearity at low volume levels.
- Fixed YabaSanshiro2Pro screen recording with no audio.
- Fixed incorrect storage reporting in Settings → Storage with and without SD card.
- Fixed black screen and missing icons after boot when using dynamic wallpaper and modifying ROM paths.
- Added controller style and trigger key settings to the quick drop-down menu.
- Added extended firmware version information when tapping the firmware version multiple times.

</details>
